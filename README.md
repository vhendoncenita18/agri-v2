# Lettuce Harvest Prediction System

Thesis project for predicting lettuce harvest using growth monitoring data.

## Project Structure
- `app/`: Android application module.
- `AGENTS.md`: Development rules.
- `ARCHITECTURE.md`: Technical stack details.
- `SYSTEM_SPEC.md`: Requirement specifications.

## Setup
1. Open in Android Studio.
2. Sync Gradle.
3. Run the `app` module on an emulator or device.
